# 🌟 모아둠 (MOADUM) - 자료를 한곳에, 정리는 한눈에

> "좋은 기록이 좋은 기회를 만들어요. 모아둠과 함께, 차근차근 준비해봐요. 💜"

취업 준비생과 직장인을 위한 스마트 자료 수집 및 일정 연계 웹 애플리케이션 **모아둠(MOADUM)** 의 실제 작동 웹사이트입니다.  
제공해주신 **예상 최종 화면 시안(4분할 고화질 디자인)**, **와이어프레임(01~18)**, **기능 명세서(엑셀 요구사항)** 를 100% 반영하여 실제 브라우저에서 모든 기능이 동작하도록 구축되었습니다.

## 🚀 빠른 실행 방법

### 방법 1. 브라우저로 바로 열기 (가장 빠름)
터미널에서 아래 명령어를 실행하거나, 파인더(Finder)에서 `index.html` 파일을 더블 클릭하세요.
```bash
open /Users/bella.mirae/.gemini/antigravity/scratch/moadum/index.html
```

### 방법 2. 원클릭 런처 실행
```bash
cd /Users/bella.mirae/.gemini/antigravity/scratch/moadum
./run.sh
```

### 방법 3. 내장 로컬 웹서버 실행
```bash
cd /Users/bella.mirae/.gemini/antigravity/scratch/moadum
python3 server.py
```
서버가 켜지면 브라우저에서 **`http://localhost:8000`** 으로 접속합니다.

## 💎 추가 구현된 핵심 와이어프레임 기능

1. **임시 보관함 & 보드 이동 (와이어프레임 04, 05)**
   - 보드나 분류를 미처 정하지 못한 자료 3건 수록 (네카라쿠배 공고 짤, 카카오 자소서 초안, 라인 채용 홈페이지)
   - 각 카드에서 `[보드로 이동]` 클릭 시 모달이 열려 원하는 보드와 세부 분류를 선택하고 즉시 이동 가능
2. **자료 상세 보기 및 삭제 (와이어프레임 07)**
   - 카드를 클릭하면 모달 팝업으로 전체 본문, 링크 새 창 열기, 태그 목록 확인 및 삭제 지원
3. **통합 검색 & 고급 검색 (와이어프레임 08, 09)**
   - 헤더 상단 검색창에 검색어 입력 시 전체 보드 실시간 검색 결과 화면 렌더링
   - 검색창 우측 슬라이더 버튼 클릭 시 기간, 다중 보드 선택, 자료 유형 복합 필터 모달 제공
4. **일정에 자료 연결 모달 (와이어프레임 13)**
   - 일정 상세 패널에서 `[+ 자료 연결]` 버튼 클릭 시 기존 저장 자료들을 검색하고 체크박스로 다중 연결/해제 가능
5. **알림 목록 드롭다운 (와이어프레임 18)**
   - 상단 벨 아이콘 클릭 시 D-1 블루베리 AI 면접, D-2 삼성전자 서류 마감 알림 표시 및 클릭 시 일정으로 바로 이동
6. **프로필 & 데이터 백업 (와이어프레임 15)**
   - 소윤님 이름, 소개글, 프로필 사진 변경
   - `[백업 파일(JSON) 다운로드]` 클릭 시 모든 자료/일정 데이터가 파일로 즉시 저장
   - `[백업 파일에서 복원하기]`를 통해 데이터 원클릭 복원 지원
7. **요금제 및 용량 관리 (와이어프레임 16, 17)**
   - 무료 플랜 (487MB / 500MB, 97% 사용 경고)
   - 프로 플랜 (월 ₩4,900, 50GB 제공, 무제한 보드)
   - `[프로 플랜으로 업그레이드]` 클릭 시 실제 50GB로 확장되는 체험 인터랙션

```

├── index.html         # 메인 웹사이트 진입점 (모든 뷰와 모달 포함)

│   └── style.css      # 모아둠 전용 세련된 디자인 시스템 및 퍼플 테마 스타일
```
